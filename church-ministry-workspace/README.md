# 교회사역 워크스페이스

교회 사역팀이 **한 곳에서 계획·실행·점검**할 수 있도록 만든 기본 워크스페이스입니다.

## 사용 방법
1. `08_일정/월간계획_템플릿.md`에 월간 일정을 작성합니다.
2. 각 사역 폴더(예배/교육/전도 등)에 주간 계획을 작성합니다.
3. 회의 후 `09_회의록/회의록_템플릿.md`로 기록하고 액션아이템을 업데이트합니다.
4. 완료된 문서는 `10_자료실`에 보관합니다.

## 폴더 구성
- `01_비전과기도`: 비전 선언문, 기도제목, 분기 목표
- `02_예배`: 예배 기획, 순서, 봉사자 배치
- `03_교육`: 새가족/성경공부/다음세대 커리큘럼
- `04_전도와선교`: 전도 계획, 선교 리포트
- `05_돌봄과심방`: 돌봄 대상자, 심방 일정
- `06_행정과재정`: 예산, 지출, 운영 체크리스트
- `07_미디어`: 주보, 영상, 디자인 요청
- `08_일정`: 주간/월간 캘린더와 행사 일정
- `09_회의록`: 사역회의 기록 및 결정사항
- `10_자료실`: 양식, 완료 문서, 참고자료
